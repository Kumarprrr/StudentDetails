# Heart Disease Prediction System

A machine learning web application that predicts whether a patient is likely to have heart disease, based on clinical measurements such as age, blood pressure, cholesterol, and ECG results. Includes single-patient and bulk (CSV) prediction, using three trained models: Logistic Regression, Decision Tree, and Random Forest.

> ⚠️ Disclaimer: This project is for educational/demonstration purposes only. It is trained on a small public dataset (~918 records) and has not been clinically validated. It should never be used as a substitute for professional medical diagnosis.

---

## Features

- Single Prediction — enter one patient's details and get predictions from 3 models
- Bulk Prediction — upload a CSV of multiple patients and download predictions as a CSV
- Model Information — view each model's accuracy, loaded dynamically from training results
- Missing value handling using a KNN Imputer (fit only on training data, avoiding data leakage)
- Backend API built with FastAPI, frontend built with Streamlit

## Setup

1. Clone/copy this project folder.
2. Create and activate a virtual environment:
   python -m venv venv
   venv\Scripts\activate
3. Install dependencies:
   pip install -r requirements.txt

---

## Running the App

This project needs two terminals running at the same time.

### Terminal 1 — Start the backend
cd Backend
uvicorn main:app --reload

Wait until you see:
Application startup complete.

### Terminal 2 — Start the frontend
streamlit run UI_Model_Heart_Prediction.py

This opens the app in your browser automatically.

---

## Retraining the Models

If you want to retrain the models with new data:

1. Open Heart_Disease_Prediction_MLModel.ipynb.
2. Run all cells in order. This will:
   - Encode categorical columns
   - Split data into train/test sets
   - Fit a KNN Imputer (on training data only)
   - Train all 3 models
   - Save updated .pkl files and model_accuracies.json
3. Copy the new .pkl files into the Backend/ folder.
4. Copy the new model_accuracies.json into the root HeartDiseaseML/ folder.
5. Restart the backend (Terminal 1) to load the new models.

## Input Features

| Feature | Description |
|---|---|
| Age | Age of the patient (years) |
| Sex | 0 = Male, 1 = Female |
| ChestPainType | 0 = Atypical Angina, 1 = Non-Anginal Pain, 2 = Asymptomatic, 3 = Typical Angina |
| RestingBP | Resting blood pressure (mm Hg) |
| Cholesterol | Serum cholesterol (mg/dl) |
| FastingBS | 1 if fasting blood sugar > 120 mg/dl, else 0 |
| RestingECG | 0 = Normal, 1 = ST-T Wave Abnormality, 2 = Left Ventricular Hypertrophy |
| MaxHR | Maximum heart rate achieved |
| ExerciseAngina | 1 = Yes, 0 = No |
| Oldpeak | ST depression induced by exercise |
| ST_Slope | 0 = Upsloping, 1 = Flat, 2 = Downsloping |
